# 笔记详情页（Note Details）— 重设计规格

> 安卓和 iOS 共用同一份规格。两个仓库的 `docs/design/note-details/` 里放的是一模一样的文件。
> 改设计时两边一起更新。
> 设计稿来源：Claude Design 画布「Note Details Redesign」，C 那一排（C1–C4）是定稿方向。
> `source/` 里是每张设计图的原始 HTML（`*.dc.html`），只在需要核对精确数值时查看，不要直接移植。
> 截图（如果有）放在 `screens/`。

## 0. 一句话

经文和笔记合成**一张卡片**。笔记的操作收进卡片底部一行（标签、星标、「⋯」），点「⋯」弹出**底部菜单**。
评论/感想按天列出，**长按**某条评论后，这条浮起来，下方出现一排操作按钮。
右下角的「+」FAB 改成底部常驻的**输入栏**。

| 设计图 | 内容 |
| --- | --- |
| `LongFirst` (C1) | 第一屏：长经文默认折叠 |
| `LongFull` (C2) | 整页滚动长图：经文展开、长笔记、卡片底部操作行、评论列表、底部输入栏 |
| `LongSheet` (C3) | 笔记「⋯」底部菜单 |
| `LongComment` (C4) | 长按评论后的操作栏 |

## 1. 颜色：一律用现有颜色

不新增颜色，只对应到现有的 `AppColors`（安卓）/ `AppColor`（iOS）。设计稿里的 hex 只是近似值。

| 用途 | 设计稿 hex | 用现有颜色 |
| --- | --- | --- |
| 页面背景 | #F2F5F4 | `pageBackground` |
| 卡片 / 菜单 / 输入栏底色 | #FFFFFF | `surface0` |
| 卡片描边、分割线 | #E2E8E7 | `neutral20` |
| 主文字 | #17262A | `neutral100` |
| 次要文字（日期、时间） | #5C6C70 | `neutral90` |
| 标签胶囊底色 | #EEF3F3 | `pageBackground`（或 `neutral20` 的 50%） |
| 顶栏类型标签（祷告） | 青色 | `prayerChip`（其他类型用各自的 chip） |
| 经文区底色 | #F7F5FC | `noteTypeBibleVerse` 6% 透明度 |
| 经文区分割线 | #ECE8F7 | `noteTypeBibleVerse` 12% |
| 经文出处、节号、「展开」文字 | #4F3F96 | **唯一新增的颜色：`scriptureInk` = #4F3F96**（`noteTypeBibleVerse` 原色做小字对比度不够） |
| 经文正文 | #2A2550 | `neutral100` 也可以 |
| 发送按钮、强调色 | #0A7FC2 | `blue80` |
| 已收藏 | #FFF4E0 / #E09A2D | `starredTile` |
| 已置顶 | #E3F1F8 / #075E91 | `pinnedTile` |
| 已应允（仅祷告） | — | `answeredPrayerTile` |
| 删除 | #FDF0EF / #C2281F | `red20` / `red80` |
| 弹窗背后的遮罩 | rgba(12,22,26,.38) | 黑色 38% |

深色模式直接用这些颜色现有的 dark 值，设计没有另外规定。

### 1.1 类型图标：沿用现有的 emoji

和 `NoteBadges.typeIcon` / iOS `listIconContent` 保持一致，不要换成线条图标。

| 类型 | 图标 + 名称 | chip 颜色 |
| --- | --- | --- |
| 祷告 | 🌿 Prayer | `prayerChip` |
| 快速笔记 | 📝 Quick note | `notesChip` |
| 学习笔记 | 📚 Study note | `notesChip` |
| 经文 / 经文出处 | ✝️ John 3:16 | 浅紫底（`noteTypeBibleVerse` 14%）+ `scriptureInk` |
| 章级笔记 | ✝️ Chapter · Exodus 1 | 同上 |
| 讲道 | 📖 Sermon | `sermonChip` |
| 视频 | ▶️ Video | `videoChip` |
| 已应允 | 🙌 Answered | `answeredPrayerTile` 的底色；文字用深绿 #1E6B33（系统绿做小字对比度不够） |

经文区的出处前面也加 ✝️，比如 `✝️ PSALM 23:1–6`。

## 2. 字号、圆角、间距

单位：安卓用 dp/sp，iOS 用 pt，数值相同。

| 元素 | 字号 / 字重 / 行高 |
| --- | --- |
| 笔记正文 | 18 / Medium / 1.7 倍行高，段落之间间距 14 |
| 经文正文 | 17 / 衬线字体（iOS 用 New York；安卓用 `FontFamily.Serif`，中文用 Noto Serif SC） / 1.6 倍 |
| 经文出处（PSALM 23:1–6） | 12 / Bold / 全大写 / 字距 0.08em |
| 节号 | 10 / Bold / 上标，颜色 `scriptureInk` 70% |
| 译本标签（KJV） | 11 / SemiBold，底色 `noteTypeBibleVerse` 12%，圆角 6 |
| 顶栏类型 | 13 / Bold；下面一行日期 12 / Regular |
| 评论正文 | 15 / Regular / 1.6 倍 |
| 评论时间 | 12 |
| 日期列 | 日 20 / Bold，星期 11 |
| 区块标题「Comments」 | 17 / Bold，旁边数量徽标 12 / SemiBold |
| 标签胶囊 | 12，左右内边距 9、上下 3 |

| 圆角 | |
| --- | --- |
| 主卡片 | 24 |
| 评论卡片 | 16 |
| 底部菜单 | 32（四角都圆，左右下各留 8 的边距，悬浮样式） |
| 菜单里的大按钮 | 18 |
| 圆形按钮、输入框 | 全圆 |

页面左右边距 16。卡片内边距左右 20、上下 18。卡片和评论区之间间距 26。
所有可点击区域至少 44pt / 48dp。

## 3. 页面结构（从上到下）

### 3.1 顶栏
- 左：返回按钮，44 圆形，白底加 1px `neutral20` 描边。
- 中（左对齐，紧挨返回键）：两行。第一行是类型标签：emoji 加类型名，用这个类型的 chip 颜色（祷告是 `🌿 Prayer`，用 `prayerChip`；笔记是 `📝 Quick note`，用 `notesChip`；见 §1.1），有星标时后面跟一个小星星。第二行是 `Mon, Oct 12, 2026 · 7:15 AM`。
- 右：「⋯」按钮，样式同返回键，打开 §4 的底部菜单。
- 背景用 `pageBackground`，不要阴影。

### 3.2 主卡片：经文 + 笔记合在一起
一张白卡片，圆角 24，1px `neutral20` 描边，内容不能溢出卡片。

**a. 经文区**（笔记带经文时才显示）
- 底色是浅紫，底部 1px 分割线。
- 标题行：经文出处，后面跟译本标签，最右边一个「›」（点了跳到圣经阅读该处）。
- 正文：多节时每节一段，节号用上标；只有一节时不显示节号。
- **折叠规则**：超过 3 节，或者文字超过 5 行时，默认折叠到大约 5 行（最大高度约 136），底部 48 高渐隐到底色，下面放「Show all N verses ⌄」按钮。展开后按钮变成「Collapse ⌃」。展开状态只在当前页面内记住。
- 经文锚点笔记（笔记本身就是一段经文）：经文就是笔记正文，没有下面的 b 区，也不折叠。

**b. 笔记正文区**
- 完整显示，不截断；保留换行，分段显示。
- 图片笔记：图片放在这里，在正文上方。

**c. 卡片底部操作行**（替代原来那排图标按钮）
- 顶部 1px 浅分割线，左内边距 20、右 8，上下 8。
- 左：标签胶囊，可换行；没有标签时这块留空，不要放「+ Tag」。
- 右：星标按钮，再右边是「⋯」按钮，都是 44 的透明按钮。
  - 星标：未收藏时是空心星（`neutral90`），已收藏时是实心星（`starredTile` 的颜色）。轻点切换 0↔1；长按（iOS 用 contextMenu）选 1–3 级星。
  - 「⋯」：和顶栏的「⋯」打开**同一个**菜单。笔记很长时，顶栏的按钮滚出屏幕，读完正文就能直接点这里。
- 有已应允、已置顶状态时，在标签前面加小图标（🙌、📌），14 大小。

### 3.3 评论区
- 标题行：「Comments」加数量徽标，最右边是月份（`OCT 2026`，12 SemiBold，大写）。经文锚点笔记的标题用「Reflections」，列的是感想。
- 按天分组：左边 36 宽的日期列（日数字和星期），右边是这一天的评论卡片，卡片之间间距 8；组和组之间间距 14。
- 评论卡片：白底、16 圆角、1px 描边，内边距左 14、上下 12、右 4。
  - 正文完整显示，不截断。
  - 下面一行：时间；有星标就跟一个 12 的小星；有标签就跟标签胶囊。
  - 右上角一个「⋯」（36 大小，加上外边距后点击区域 44），作用和长按一样。
- 「已应允」标记评论：正文换成绿色的「🙌 Answered」加时间，样式不变。
- 置顶记录（PinLog，N2）：作为一行灰色小字插在对应日期里，比如「📌 Pinned · 9:02 AM」，不做成卡片。
- 跨月份时，在组之间插一个月份标题。

### 3.4 底部输入栏（替代 FAB）
- 白底，顶部 1px 描边，内边距 左右 16、上 10、下面加上系统安全区。
- 左：输入框，高 44，全圆角，底色 `pageBackground`，带描边，占位文字「Add a comment…」（经文锚点用「Add a reflection…」）。
- 右：发送按钮，44 圆形，`blue80` 底、白色上箭头；输入为空时变灰禁用。
- 输入框获得焦点后最多长到 5 行。祷告且还没应允时，输入框上方出现一个「🙌 Answered today」开关胶囊，对应现在 `CommentSheet` 里的开关。
- 输入栏跟着键盘上移（安卓 `imePadding()`，iOS 用 safeAreaInset）。
- 列表底部要留出输入栏的高度，最后一条评论不能被挡住。

## 4. 笔记「⋯」底部菜单（C3）

安卓用 `ModalBottomSheet`（隐藏默认拖拽条，自己画一个 36×5 的灰条，或者直接用默认的），iOS 用 `.sheet` 加 `.presentationDetents([.medium])`，或者自定义悬浮卡片。

从上到下：
1. 拖拽条。
2. **预览**：经文出处（12 Bold，`scriptureInk`）加笔记第一行（14，`neutral90`，单行省略）。
3. **4 格大按钮**（每格高 76、圆角 18，默认底色 `pageBackground`，激活后换成对应颜色）：
   - **Edit**（经文锚点、图片笔记不显示，后面的往前补位）
   - **Copy**
   - **Pin / Pinned**（激活用 `pinnedTile`）
   - **Star / Starred**（激活用 `starredTile`；点了打开现有的星级选择）
   - 祷告笔记多一个 **Answered**（激活用 `answeredPrayerTile`），这时改成 5 格，或者两行各 3 格；推荐 5 格，每格宽度相等。
4. **列表组**（底色 `pageBackground`，圆角 18，每行高 52，行之间有缩进的分割线）：
   - Tags：右边灰字显示现有标签（最多 2 个，多的写「+N」），点了打开现有的 `TagPicker`
   - Add comment：聚焦底部输入框（菜单关掉）
   - Change verse：只有带经文的笔记显示，右边灰字显示出处（如果这个功能还没有就先不显示）
5. **Delete note**：单独一组，底色 `red20`，文字和图标用 `red80`，点了先弹确认对话框。

## 5. 评论的操作（C4，对应 N2）

- 触发方式：长按评论卡片，或点卡片上的「⋯」。
- 效果：背景加遮罩（iOS 可以加 3pt 模糊；安卓 12 以上可以用 `Modifier.blur` 模糊背景，低版本只加遮罩），被选中的评论卡片浮在原来的位置上，加阴影 `0 12 32 / 22%`，正文完整显示，下面一行写完整日期。
- 卡片下方 10 处是一排操作，白底、圆角 20、内边距 6，平均分成 5 格，每格高 58，图标 20 在上、文字 11 在下：
  **Edit · Copy · Star · Tags · Delete**（Delete 用 `red80`；已收藏、有标签时这一格高亮，比如显示「Tags · 1」）
- 操作栏放不下时（评论靠近屏幕底部），改成放在卡片**上方**；卡片太高的话，先把它滚动到可见的位置。
- 安卓实现：用 `Popup` 或全屏 `Dialog`，在里面把卡片按测量到的位置重新画一遍；iOS 用 `.contextMenu(menuItems:preview:)` 也可以，但样式会是系统样式。要和设计一致的话，就做一个自定义 overlay。
- 点遮罩或按返回键关闭。

## 6. 交互和状态清单

- [ ] 经文 ≤3 节且 ≤5 行时：不折叠，没有展开按钮
- [ ] 经文 >3 节或 >5 行时：折叠，底部渐隐，显示「Show all N verses」
- [ ] 笔记没有经文时：卡片只有笔记正文区和底部操作行
- [ ] 经文锚点笔记：卡片里只有经文（不折叠），标题叫 Reflections，占位文字是「Add a reflection…」
- [ ] 没有标签时：底部操作行只有星标和「⋯」，右对齐
- [ ] 没有评论时：标题下面显示灰字「No comments yet」，输入栏照常显示
- [ ] 很长的笔记、很长的评论都完整显示，不截断
- [ ] 顶栏「⋯」和卡片底部「⋯」打开同一个菜单
- [ ] 星标轻点切换，长按选级别
- [ ] 删除要确认；删除后返回上一页（现在 `state.gone` 的逻辑）
- [ ] 深色模式：所有颜色都来自现有颜色表

## 7. 和现有安卓代码的对应

| 现在 | 改成 |
| --- | --- |
| `TopAppBar` 加居中的 `NoteBadgeChip` | 自定义顶栏（§3.1） |
| `LinkedVerseCard` 和 `BodyCard` 是两张卡片 | 一个 `NoteMainCard`，里面有经文区、正文区、底部操作行 |
| 日期加 `NoteStatusIndicators` 单独一行 | 日期挪到顶栏，状态放进卡片底部操作行 |
| `NoteActionsMenuButton` 用 `DropdownMenu` | 一个 `NoteActionsSheet`（`ModalBottomSheet`），`NoteAction` 不变；列表页的「⋯」也可以用同一个菜单 |
| `CommentLine` 加分割线 | `CommentCard`，按天分组，左边是日期列 |
| `FloatingActionButton` 加 `CommentSheet` | 底部输入栏 `CommentComposer`（带「Answered today」开关） |

数据层、`NoteAction`、写入格式都**不改**，这次只改 UI。
