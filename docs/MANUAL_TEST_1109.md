## B. 笔记详情页改版（约 15 分钟，用「测试祷告 A」）

### 卡片顶部
18. 打开详情页 → 卡片左上是**大号黄色日号**，旁边两行小字：「月 · 星期」和「年 · 时间」。
19. 标签靠右、与日号同一行；标签名前**没有 #**（见 E 组）。
20. 无标签的笔记 → 右侧留空，布局不乱。

### 卡片底部图标行
21. 看到一排图标：🙌/🙏、复制、置顶、删除、评论气泡、星级、标签（带数量）、编辑。
22. 点复制 → 出现「已复制」提示；粘贴到别处是笔记正文。
23. 点置顶 → 图标变为已置顶；再点 → 取消置顶（按手机日期判断「今天」是否在置顶日里，见准备 0）。
24. 点 🙌 → 变为已应允（祷告）；再点 → 取消。
25. 点星级 → 就地出现 1–3 星选项（行内，不弹窗）；选 3 → 图标显示 3 星；再选取消星 → 回到无星。
26. 点标签（图标上有数量）→ 打开标签面板；加一个标签，关闭 → 数量 +1。
27. 点删除 → 有确认；取消后笔记还在。（别点确认，除非是测试笔记）
28. 点编辑 → 能改正文，保存后详情更新。
29. 点评论气泡 → 输入条获得焦点、键盘弹出。

### 评论线程
30. 评论按**天**分卡片：同一天的评论在同一张卡片里，评论之间有 1px 分隔线。
31. 左侧日期列：当天显示「今天」，前一天显示「昨天」，更早显示周几（周一…）。注意是**手机日期**。
32. 相邻两天之间有**竖连接线**；中间隔着月份标题行的两天**不连线**。
33. 评论上的图标行（复制、删除、星级、标签、编辑）常驻；长按或 ⋯ 仍有额外入口（需确认哪一处有）。
34. 只有置顶没有评论的日子 → 显示「日号 📌」，连续置顶合成一行「已置顶 · 日期范围」。
35. 没有任何评论的笔记 → 只显示「暂无评论。」，没有标题、没有数量。

### 已应允折叠与评论数
36. 「配对」的已应允（准备里勾选 + 写了字的那条）→ 没有单独的「已应允」卡片；该评论**第一行**显示 🙌。
37. 「不配对」的已应允（只勾选没写字）→ 单独一行「🙌 今日已应允」。
38. 评论数 = 全部评论 − 已配对的标记。例：4 条评论里 1 条是配对标记 → 标题显示 3；不配对的标记**算在内**。
39. 当天有任何已应允标记时，当天不再额外出现「已应允」行（不重复）。

### 输入条
40. 没聚焦、没字 → 输入条上**看不到**「标记为已应允」勾选。
41. 点进输入框 → 勾选出现；输入文字后（失焦）勾选仍在。
42. 清空文字并失焦 → 勾选再次消失。
43. 已应允的祷告 → 输入条不再出现该勾选。
44. **键盘弹出**：整页**不被顶上去**，顶栏仍在屏幕上；输入条紧贴键盘上方，不被键盘挡住、也不离键盘一大截。
45. 发送一条带勾选的评论 → 评论首行出现 🙌，评论数 +1。

### 章节经文页感想区（之前没核对过）
入口：「今天」→ 阅读轮播里长按某一章（或「今日动态」里某章的「笔记」）→ 章节页切到**章节笔记**tab → 点某节经文进入经文页。
46. 在经文页「写感想…」发一条感想 → 出现在「感想」线程里；格式与详情页线程一致（按天卡片、日期列、连接线）。
47. 经文页上给感想加 🙌 配对（勾选已应允）→ 与 B-36、B-37 同样折叠；计数「N 条感想」按相同规则算。
48. 键盘弹出时经文页输入条不被挡住（与 B-44 同标准）。

### 回顾页（之前没核对过）

## C. Transform 预设标签与特效（约 15 分钟）

### 识别与显示
51. 在「测试笔记 B」的标签面板里，**推荐**行应出现 **Transform**（和 Trash、Milestone 同一行）。点它 → 加上，名字前有 🦋。
52. 手动输入名字（逐个试，都应识别为 Transform，名字前出现 🦋）：`TRANSFORM`（大写）、`  transformed `（首尾带空格）、`transformation`、`转化`、`轉化`（繁体）、`蜕变`、`蛻變`。每个都新建一条标签并加到某条笔记上。
53. 这些标签在笔记卡片、详情页、标签列表里都显示 🦋；别的普通标签没有 🦋。
54. 已有 Transform 标签后，推荐行里**不再重复**出现 Transform。

### 特效（用「测试笔记 B」，建议文字多一点）
55. 打开某笔记 → 标签面板 → 加 Transform → **关闭面板** → 约 0.35 秒后自动播放。
56. 播放过程：文字带**紫色光晕**，向两侧略微撑开 → **一闪** → 蝴蝶和星星散开 → 收回，文字恢复原样。
57. 播放时有轻微震动（线性马达/触感），结束时再一下（需确认三星是否有感觉，没有不算错）。
58. 播放期间**手指触摸能穿透**：点屏幕任何位置或滚动页面，不被挡住。
59. 选中一个**已存在**的 Transform 标签（面板里的已有标签 chip）并关闭面板 → 同样自动播放。
60. 加了 Transform 又在面板里去掉后关闭 → **不播放**。
61. 点笔记（卡片/详情页）上的 🦋 标签胶囊 → 重播特效。
62. 点评论上的 🦋 标签（需先在评论的标签面板里手输 `Transform` 加上）→ 重播，评论文字有光晕。**注意：评论的标签面板没有「推荐」行，加完也不会自动播放，只有点胶囊才播——这是现状，不算错**（需确认你是否希望评论也自动播放，告诉我）。
63. 特效播放到一半，快速再点一次胶囊 → 不会叠加成两份。

### 边界
64. **没有文字的笔记**（准备 3 的图片笔记）上加 Transform 并关闭 → 蝴蝶/星星从图片卡片/标签胶囊位置散开，无崩溃。
65. 手机**开发者选项 → 动画时长缩放 = 关闭**（Android 的「动画程序时长缩放」）→ 再做 55 → **不播放**，也不崩溃。测完改回 1x。
66. Transform 笔记所在位置被滚出屏幕后再点胶囊 → 无崩溃（有无特效不强求）。
67. 在**章节经文页**和**回顾页**的笔记上点 🦋 → 若可点则重播；不能点也行（需确认）。

### 三种语言的推荐行文案
应用语言跟随系统语言（需确认设置里是否有应用内切换；没有就去手机「设置 → 一般管理 → 语言」切）。
68. 英文：推荐行标题「Recommended」，三个 chip：Trash、Milestone、Transform（前缀 🗑️ / 🏆 / 🦋）。
69. 简体：标题「推荐」，chip：回收站、里程碑、转化。
70. 繁体：标题「推薦」，chip：回收站、里程碑、轉化。
71. 繁体下加上「轉化」后，识别为 Transform（有 🦋、能触发特效）。
