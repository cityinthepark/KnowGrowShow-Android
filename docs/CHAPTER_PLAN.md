# 章节页 — 安卓方案

**已确认（2026-10-27）**：§4 三个问题都照推荐。**状态：已完成（未提交）**，实现与验证见 §6、§7。

依据（iOS 代码为准）：`ChapterDetailView`、`ChapterSermonView`（`SermonRow`）、`ChapterNoteView`（`ChapterNoteViewModel`）、
`ChapterNoteDetailsView`（`ChapterNoteEntrySheet`）、`BibleAnchor.swift` 的 `ChapterNoteAnchor`、`NoteInputSheetView`（`defaultBookChapter`），
以及 `NotesManager` 的 `getNoteComments(for: BookChapter)`、`getPrayerNotes`、`getChapterNotes`、`getVerseReflectionNotes`、
`getBibleVerseNote`、`linkedReflectionNotes`、`addNote(_:to:…)` → `saveSeparatedNoteInput(anchorChapter:)`、`fetchSermonsByBibleChapter`。

## 1. iOS 的结构

**入口**（现在安卓这三处都是"即将推出"）
- Today 读经卡片：**长按**章节按钮 → 章节页（讲道 tab）。
- 阅读记录页：**长按**章节 → 章节页（讲道 tab）。
- Today 今日活动"读过的章节"每一行：「讲道」「笔记」两个按钮 → 打开对应 tab（今天的行前面还有「未读」）。

**章节页**：标题是章名（"创世记 2"），顶部分段「章节讲道 | 章节笔记」，可左右滑动切换。

**讲道 tab**：这一章的讲道（同一卷书，且讲道的章节列表包含本章），按讲道年份分组，新的年份在前。每行：
经文范围、讲道日期、展开箭头（展开后显示简介）、标题（点进讲道页）、讲员；有音频 / YouTube / PDF 时右边"⋯"：听、看、读。

**笔记 tab**：按位置分组，整章一组排最前，之后每节（或节范围）一组，按节号排。内容有四种来源：
1. 评论（`NoteComment` 上带着章节）；
2. 挂在某节上的祷告；
3. 整章笔记（笔记 / 学习笔记，只有章、没有节）；
4. 某节的感想（笔记 / 学习笔记，有节）。

每组显示：
- 标题：整章组显示"章节笔记"；节组显示经文标签和经文正文（含划线）。
- 摘要行"N 条评论 · M 个祷告"，点进**节详情**。
- 整章笔记卡片：日期和正文，不能点。

底部"＋"打开新建笔记弹窗，引用框预填"创世记 2"。保存规则和 Today 的新建笔记相同，另外多一条"挂到本章"：
- 引用到节：保存经文锚点和感想；
- 引用只到章或为空：保存普通笔记，挂在本章（写 `bookOrd`、`chapterOrd`，`refKey` 写章键）；
- 正文开头写 `vN`：按本章的第 N 节保存。

**节详情**（`ChapterNoteDetailsView`）：
- 顶部：经文标签，加锚点的"⋯"菜单。
- 经文正文卡片。
- 「评论 (N)」：感想，加上锚点下的旧评论。
- 「祷告 (N)」：每条显示已应允标记、正文、日期、"⋯"。
- 底部"＋"弹窗：分段选「评论 | 祷告」，引用固定不能改。这一节还没有锚点时只能写祷告。

## 2. 安卓做法

- **结构和信息与 iOS 相同**，用安卓原生组件：顶栏显示章名；`TabRow` 加可滑动的分页切换两个 tab；
  "＋"和新建弹窗沿用 Today；"⋯"沿用笔记列表 / 详情已有的底部菜单（设计 C3 / C4）。
  卡片、经文块、划线的样式沿用 `docs/design` 的笔记列表和详情设计。
- **用词**：经文锚点下面一律叫"感想"，与笔记详情一致。摘要行写"3 条感想 · 2 个祷告"，详情分段写「感想 (3)」，
  新建弹窗写「感想 | 祷告」，空状态写"还没有感想或祷告"。整章笔记下面的仍叫"评论"。
- **讲道 tab 加空状态**："这一章还没有讲道"（iOS 显示空白）。本机用户在 T3 之前不能新建讲道，这里通常是空的；
  从云端同步下来的讲道会照常显示。
- **讲道页**（`SermonNoteView`）属于 T3：现在点讲道标题会显示"即将推出"；"⋯"里的看、听、读见 §4 问题 3。
- **数据自动刷新**：页面数据来自 Room，有变化时界面自动更新（iOS 的讲道列表只在页面出现时读取一次）。
- **整章笔记卡片可以点**：点开进入已有的笔记详情，在那里看评论、编辑、删除（iOS 的卡片不能点，章节页里改不了整章笔记）。
- **只写已有格式**：本阶段只新建笔记、感想、祷告（复用已有的保存逻辑，加上"挂到本章"这一支），以及已有的笔记操作。
  不新增任何 Firestore 字段，写入格式与 iOS 一致。

## 3. 发现的 iOS 问题（安卓直接修正，会写进 `IOS_ISSUES.md` 新的 H 节）

| | iOS 位置 | 问题 | 影响 | 安卓做法 | iOS 修了以后安卓要改吗 |
| --- | --- | --- | --- | --- | --- |
| H1 🔴 | `ChapterNoteDetailsView.verseNote` → `getBibleVerseNote(…).first` | 锚点按天去重，同一节在不同的日子会有好几个锚点；节详情只取其中一个（一般是最早的那个），只显示那一天的感想，但列表摘要数的是所有日子的感想。查询还要求 `verseEnd` 完全相等（同 F3）。 | 列表写"3 条"，点进去只有 1 条；在节详情里新加的感想挂在今天的新锚点上（G5），加完在这一页看不到 | 节详情汇总这一节**所有锚点**（所有日子、所有译本）的感想和旧评论；顶部"⋯"作用于最新的锚点 | iOS 照这样修就不用 |
| H2 🔴 | `ChapterNoteView` 整章组的摘要行 | 整章笔记上的评论会带上章节（`addNoteComment` 会复制），所以被算进整章组的"N 条评论"；可是点进去的节详情按"节"查，整章组没有节 | 点进去显示"暂无评论或祷告" | 整章组不显示摘要行；每张整章笔记卡片显示自己的评论数，点开进笔记详情看评论 | 不用 |
| H3 🟡 | `ChapterNoteViewModel.groupedEntries` 的计数 | 摘要行数的和节详情显示的不是同一批：感想笔记上的评论也带着节，算进了数量，但节详情不显示 | 数量对不上 | 摘要只数节详情里会显示的内容 | 不用 |
| H4 🟡 | `ChapterNoteViewModel` 的四种来源 | 只保存了经文、没写感想的锚点（例如在 Today 只填"约翰福音 3:16"）不属于任何一种来源 | 这一节在章节笔记里完全不出现 | 见 §4 问题 2 | 视决定而定 |
| H5 🟡 | `saveSeparatedNoteInput(anchorChapter:)` | 引用框预填本章；用户改成别的章（只到章）时，正文的 `vN` 按**改后的章**算，普通笔记却仍挂在**本章**。同一个函数里前后不一致 | 笔记挂错章 | 两种情况都按引用框里的章；引用框清空时挂本章（与 iOS 相同） | 不用 |
| H6 🟡 | `ChapterSermonView.groupedSermons` | 同一年内的讲道不排序（按 Realm 原始顺序）；没有日期的"Unknown"组排在最前面（字母比较 `U` > `2`），而且"Unknown"没有翻译 | 顺序不稳定 | 年内按讲道日期从新到旧；没有日期的放最后，显示"日期不详" | 不用 |
| H7 🟡 | `ChapterPlainNoteRow` | 整章笔记卡片不能点 | 在章节页里无法编辑、删除整章笔记 | 点开进笔记详情 | 不用 |

## 4. 需要你确认

1. **长按章节默认打开哪个 tab**：
   **照 iOS 打开讲道 tab（推荐）**，没有讲道时显示空状态；或者这一章没有讲道时自动打开笔记 tab。
2. **只有经文、没有感想的锚点**要不要在章节笔记里显示（H4）：
   **显示（推荐）**，只显示经文和正文，没有摘要行，点开进节详情可以加感想；或者照 iOS 不显示。
3. **T3 之前讲道"⋯"里的看、听、读**：
   **用系统打开链接（推荐）**，YouTube 交给 YouTube App 或浏览器，音频和 PDF 交给浏览器，T3 做好讲道页后改成在 App 内播放；
   或者 T3 之前先隐藏"⋯"。

## 6. 实现（2026-10-27）

- **数据**：`data/chapter/ChapterNotes.kt`（`ChapterVerse`、`ChapterNotesBuilder`：整章笔记、按节分组、计数）、
  `data/chapter/ChapterSermons.kt`（按章筛选、按年分组、链接与日期）；Room 新查询：本章笔记、这些笔记的评论、
  本章 `userVerses`、本书讲道。
- **保存**：`NoteRepository.saveNoteFromContent(…, anchorChapter)` 加"挂到本章"分支（H5）；
  `saveVerseReflection`（节详情写感想：今天、主译本的锚点；这一节还没有锚点也可以写）、
  `savePrayerOnVerses`（节详情写祷告：直接用节号，不再把引用转成文字再解析）。写入字段与 iOS 相同。
- **界面**：`ui/chapter/`：章节页（顶栏 + 两个 tab，可左右滑；讲道卡片、整章笔记卡片、节卡片；"＋"沿用 Today 的
  新建笔记弹窗，预填本章、按 `.chapterAnchored` 校验）、节详情页（沿用笔记详情的经文卡片、按天的感想列表、底部输入栏，
  输入栏上方加「感想 | 祷告」切换）。三个入口都已接上。
- **顺带改的**（为了"锚点下一律叫感想"）：笔记列表 / 详情里锚点的"⋯"改为「写感想」，弹出的输入框标题也是感想；
  笔记详情里锚点没有感想时显示"还没有感想"。
- 做的过程中又记了两条 iOS 小问题：H8（锚点下用词）、H9（讲道卡片），见 `IOS_ISSUES.md`。
