## E4 输入条和文案（直接做）

- 「已应允的祷告不再显示勾选」：安卓规则已和 iOS 一致，不用改。
- 勾选只在输入框聚焦或有文字时显示（iOS 同样）。
- 勾选加无障碍说明「标记为已应允」（`action_mark_answered`，三语已有）。
- 文案：`answered_today` 中文改成 iOS 的「今日已应允 / 今日已應允」（现在是「今天」）。

## 不照 iOS 的地方

- iOS 输入条的问题（IOS_ISSUES O4）：勾选被隐藏后仍生效，可能多出一条标记。安卓发送时检查 `canMarkAnswered`，不跟这个问题。
- 连接线：iOS 的规则是笔记一旦有过置顶段，不在同一段里的相邻日子就不连线，像是没想好。待你确认后，安卓先按「相邻就连」做。
